# โปรโตคอลถ่ายภาพ (ส่วนที่ 1)

วัดด้วยเวอร์เนีย ชนิดละ 3 เหรียญ (ต่างปี) แล้วอัปเดต `backend/schemas/coin_types.py` ถ้าค่าเฉลี่ยต่างจากตารางเกิน 0.1 มม.

| ชนิด | ค่าในแผน (มม.) | เหรียญ 1 | เหรียญ 2 | เหรียญ 3 | เฉลี่ย |
|---|---|---|---|---|---|
| 25 สตางค์ | 16 | 16.00 | | | |
| 50 สตางค์ | 18 | 18.00 | | | |
| 1 บาท | 20 | 20.00 | | | |
| 2 บาท | 21.75 | 21.75 | | | |
| 5 บาท | 24 | 24 | | | |
| 10 บาท | 26 | 25.60 | 25.60 | 25.60 | 25.60 (4 เหรียญ) |

## ตัวแปรที่ต้องคละให้ครบ

| ตัวแปร | ค่า |
|---|---|
| พื้นหลัง | กระดาษขาว, โต๊ะไม้, ผ้าสีเข้ม (อย่างน้อย 3 แบบ) |
| แสง | แสงห้องปกติ, แสงหน้าต่าง, แฟลช/ไฟตรงจนมีเงา |
| มุมกล้อง | ตรงจากด้านบน, เอียง ~15°, เอียง ~30° |
| จำนวนเหรียญ | 3–30 เหรียญต่อภาพ |
| การวาง | กระจาย, ชิดกัน, ซ้อนกันเล็กน้อย (เห็นเกินครึ่งเหรียญ) |
| ด้าน | คละหัวและก้อย |
| ภาพสเกลไม่ชัด | ~10 ภาพที่มีเหรียญกลุ่มสีเดียวขนาดเดียว (เช่น 1 บาทล้วน) |

## เป้าจำนวน

- ภาพของทีม ~150 ภาพ, ภาพจากเว็บ ~30 ภาพ
- ทุกชนิดเหรียญรวมกันอย่างน้อยชนิดละ 80 เหรียญ
- สัปดาห์ 1: ภาพชุดแรก 30 ภาพ และเลือก 5–10 ภาพใส่ `data/samples/`

## การตั้งชื่อไฟล์

`<ผู้ถ่าย>_<พื้นหลัง>_<แสง>_<มุม>_<ลำดับ>.jpg` เช่น `p1_white_room_top_001.jpg`

ใช้รหัสตามตารางนี้ (ห้ามมี `_` ในแต่ละช่อง เพราะ `data/dataset.py` แยกช่องด้วย `_` เพื่อแบ่ง split ให้ครบทุกเงื่อนไข)

| ช่อง | รหัส |
|---|---|
| ผู้ถ่าย | `p1` … `p5` |
| พื้นหลัง | `white` กระดาษขาว, `wood` โต๊ะไม้, `cloth` ผ้าสีเข้ม (แบบอื่นตั้งรหัสใหม่ได้ เช่น `tile`) |
| แสง | `room` แสงห้อง, `window` แสงหน้าต่าง, `flash` แฟลช/ไฟตรง |
| มุม | `top` ตรงจากด้านบน, `tilt15`, `tilt30` |
| ลำดับ | ตัวเลข 3 หลัก เช่น `001` |

ภาพจากเว็บ: `web_<ลำดับ>.jpg` และบันทึกแหล่งที่มาใน `data/web_sources.csv` (`file,url,accessed_date`)

ถ่ายด้วยความละเอียดเต็มของกล้อง ไม่ต้องย่อหรือแต่งภาพ

## ตรวจความครบ

```bash
python data/dataset.py check
```

แสดงจำนวนเหรียญแต่ละชนิดเทียบเป้า 80 เหรียญ, พื้นหลัง/แสง/มุมที่มีแล้ว, ภาพที่ยังไม่มีป้ายกำกับ, ชื่อไฟล์ที่ผิดรูปแบบ และป้ายกำกับที่ผิด (exit code 1 ถ้ามีข้อผิดพลาด)

## ทดลองการปรับปรุงภาพ

```bash
python data/preprocess_experiment.py          # ใช้ชุด tune
```

เปรียบเทียบ `none` / `he` (Histogram Equalization) / `clahe` (วิธีที่ใช้อยู่) / `clahe+wb` (เพิ่ม gray-world white balance) วัด Precision/Recall และความคลาดรัศมีของการหาเหรียญ กับความถูกต้องของกลุ่มสีและชนิด ผลอยู่ที่ `data/results/preprocess_experiment.md` ใช้เป็นตารางก่อน/หลังปรับปรุงภาพในรายงาน
