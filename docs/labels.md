# รูปแบบป้ายกำกับ

หนึ่งภาพ = หนึ่งไฟล์ `data/labels/<ชื่อภาพไม่มีนามสกุล>.json` พิกัดเป็นพิกเซลของ**ภาพต้นฉบับหลังหมุนตาม EXIF** (ยังไม่ย่อ)

```json
{
  "image": "p1_white_room_top_001.jpg",
  "image_size": [4032, 3024],
  "coins": [
    {"center_xy": [1203.5, 880.0], "radius_px": 142.0, "coin_type": "THB_10"},
    {"center_xy": [1650.0, 910.5], "radius_px": 108.0, "coin_type": "THB_1"}
  ],
  "notes": ""
}
```

- `coin_type` ใช้รหัสเดียวกับ schema กลาง (`THB_0_25` … `THB_10`, `unknown`)
- เหรียญที่ซ้อนจนเห็นไม่ถึงครึ่ง: ไม่ต้องใส่ และเขียนใน `notes`
- ภาพเอียง: ใส่ `radius_px` เป็นครึ่งหนึ่งของแกนยาว

## `data/splits.csv`

```csv
image,split
p1_white_room_top_001.jpg,tune
p2_wood_window_tilt15_004.jpg,test
web_001.jpg,web
```

`split` ∈ `tune` (ชุดปรับระบบ) / `test` (ชุดทดสอบ, ล็อกสัปดาห์ 3) / `web` (ชุดภาพเว็บ)

ไม่ต้องเขียนเอง ใช้

```bash
python data/dataset.py split --dry-run   # ดูก่อน
python data/dataset.py split             # เขียน data/splits.csv
```

- เพิ่มเฉพาะภาพที่มีป้ายกำกับแล้วแต่ยังไม่อยู่ในไฟล์ **ภาพที่อยู่แล้วไม่ถูกย้าย** เพิ่มภาพทีหลังได้โดยชุด test เดิมไม่เปลี่ยน
- `web_*` ไป `web`, ภาพของทีมแบ่ง `test` 30% (`--test-frac`) แยกตามกลุ่ม (พื้นหลัง, แสง, มุม) ให้ทุกเงื่อนไขอยู่ในชุด test
- ลำดับตัดสินด้วย hash ของชื่อไฟล์ รันกี่ครั้งก็ได้ผลเดิม

## ทำป้ายกำกับเร็วขึ้นด้วยหน้าเว็บ

อัปโหลดภาพ (ตั้งชื่อตามโปรโตคอลก่อนอัปโหลด) ในหน้าเว็บ ให้ระบบเดาก่อน แก้ชนิด/ลบ/เพิ่มเหรียญให้ถูก แล้วดาวน์โหลด `GET /api/labels/export` (ส่วนที่ 4) เป็น `labels.zip` และนำเข้า

```bash
python data/dataset.py import labels.zip   # แตกลง data/raw และ data/labels ใช้ชื่อไฟล์เดิมที่อัปโหลด
python data/dataset.py check
```

ภาพที่ถ่ายผ่านปุ่ม "ถ่ายรูป" ในหน้าเว็บได้ชื่อ `capture.jpg` จึงถูกนำเข้าด้วยชื่อ analysis_id ต้องเปลี่ยนชื่อภาพและไฟล์ป้ายกำกับให้ตรงโปรโตคอลเอง ไม่เขียนทับไฟล์ที่มีอยู่แล้ว
