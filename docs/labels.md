# รูปแบบป้ายกำกับ

หนึ่งภาพ = หนึ่งไฟล์ `data/labels/<ชื่อภาพไม่มีนามสกุล>.json` พิกัดเป็นพิกเซลของ**ภาพต้นฉบับหลังหมุนตาม EXIF** (ยังไม่ย่อ)

```json
{
  "image": "p1_white_room_top_001.jpg",
  "image_size": [4032, 3024],
  "coins": [
    {"center_xy": [1203.5, 880.0], "radius_px": 142.0, "coin_type": "THB_10"},
    {"center_xy": [1650.0, 910.5], "radius_px": 108.0, "coin_type": "THB_1"}
  ],
  "notes": ""
}
```

- `coin_type` ใช้รหัสเดียวกับ schema กลาง (`THB_0_25` … `THB_10`, `unknown`)
- เหรียญที่ซ้อนจนเห็นไม่ถึงครึ่ง: ไม่ต้องใส่ และเขียนใน `notes`
- ภาพเอียง: ใส่ `radius_px` เป็นครึ่งหนึ่งของแกนยาว

## ติดป้าย

```bash
python data/label_tool.py            # เริ่มที่ภาพแรกใน data/raw ที่ยังไม่มีป้าย
```

ลากจากกลางเหรียญไปขอบเพื่อวาดวง กดเลขเลือกชนิด (1=25 สต. 2=50 สต. 3=1 4=2 5=5 6=10 บาท 0=unknown) คลิกขวาลบ
`n` / `p` ไปภาพถัดไป/ก่อนหน้า บันทึกลง `data/labels/` ทันที วิธีใช้ทั้งหมดอยู่ต้นไฟล์ `data/label_tool.py`

วาดวงเองทุกเหรียญ ไม่ใช้ผลของระบบเป็นจุดเริ่ม เพราะป้ายใช้วัดผลระบบ (การกดเพิ่มเหรียญในหน้าเว็บรวมเหรียญที่ชิดกันเป็นวงเดียว
จึงไม่เหมาะทำป้าย) ส่วน `python data/dataset.py import labels.zip` ยังใช้นำเข้าผลที่แก้ในหน้าเว็บได้ ถ้ามีภาพนี้ใน `raw/` แล้ว
จะเขียนเฉพาะป้าย

## `data/splits.csv`

```csv
image,split
p1_white_room_top_001.jpg,tune
p2_wood_window_tilt15_004.jpg,test
web_001.jpg,web
```

`split` ∈ `tune` (ชุดปรับระบบ) / `test` (ชุดทดสอบ, ล็อกสัปดาห์ 3) / `web` (ชุดภาพเว็บ) / `synth` (ภาพสังเคราะห์)

ไม่ต้องเขียนเอง ใช้

```bash
python data/dataset.py split --dry-run   # ดูก่อน
python data/dataset.py split             # เขียน data/splits.csv
```

- เพิ่มเฉพาะภาพที่มีป้ายกำกับแล้วแต่ยังไม่อยู่ในไฟล์ **ภาพที่อยู่แล้วไม่ถูกย้าย** เพิ่มภาพทีหลังได้โดยชุด test เดิมไม่เปลี่ยน
- `web_*` ไป `web`, ภาพของทีมแบ่ง `test` 30% (`--test-frac`) แยกตามกลุ่ม (พื้นหลัง, แสง, มุม) ให้ทุกเงื่อนไขอยู่ในชุด test
- ลำดับตัดสินด้วย hash ของชื่อไฟล์ รันกี่ครั้งก็ได้ผลเดิม
- **หลังล็อกชุด test** ใช้ `python data/dataset.py split --test-frac 0` ภาพที่เพิ่มทีหลังจะไป `tune` ทั้งหมด ชุด test คงเดิม

## ภาพสังเคราะห์ (`synth_*`)

เหรียญ 2 บาทหายาก จึงสร้างภาพเพิ่มด้วยการตัดเหรียญจริงจากภาพในชุด `tune` ไปวางบนภาพจริงอีกภาพ (ย่อตามสเกลของภาพฐาน หมุนสุ่ม
ปรับความสว่างตามพื้นหลัง ไม่ทับเหรียญเดิม) ได้ภาพพร้อมป้ายทันที

```bash
python data/synth_coins.py --count 20      # --coin THB_0_25 ใช้กับชนิดอื่นได้
python data/dataset.py split               # synth_* ไป split synth เสมอ
```

- ใช้เฉพาะภาพมุมตรงในชุด `tune` เป็นต้นทางและภาพฐาน ไม่แตะชุด `test`
- ป้ายของเหรียญที่วางมี `"synthetic": {...}` บอกภาพต้นทาง มุมหมุน และค่าความสว่าง ส่วนป้ายทั้งไฟล์มี `"synthetic": {"base": ...}`
- **ไม่นับในเป้า 80 เหรียญต่อชนิดและไม่เข้า `test`** (`check` แสดงในคอลัมน์ `synth` แยก) เพราะเป็นเหรียญจริงชุดเดิมที่วางซ้ำ ไม่มีเงา
  ไม่ได้เพิ่มความหลากหลายของสีหรือลาย ใช้ได้กับการทดลองบนชุดปรับระบบ เช่น `python eval/run_eval.py --split synth`
  ถ้าใช้ในรายงานต้องเขียนว่าเป็นภาพสังเคราะห์
- เหรียญต้นทางมาจากชุด `tune` ชุดเดียวกับที่ `run_eval.py` ใช้สร้าง template ผล `color+scale+template` บน `--split synth`
  จึงดีเกินจริง ใช้เทียบวิธีอื่นได้ แต่ไม่ใช้เป็นตัวเลขความแม่นของ template
- สคริปต์ตั้งชื่อภาพต่อจากลำดับสูงสุดของ `synth_*` ที่มีอยู่ ถ้าจะสร้างชุดเดิมใหม่ (เช่น หลังแก้ขนาดเหรียญ) ให้ลบ
  `data/raw/synth_*`, `data/labels/synth_*.json` และแถว `synth_*` ใน `splits.csv` ก่อน แล้วรันด้วย seed เดิม

## ทำป้ายกำกับเร็วขึ้นด้วยหน้าเว็บ

อัปโหลดภาพ (ตั้งชื่อตามโปรโตคอลก่อนอัปโหลด) ในหน้าเว็บ ให้ระบบเดาก่อน แก้ชนิด/ลบ/เพิ่มเหรียญให้ถูก แล้วดาวน์โหลด `GET /api/labels/export` (ส่วนที่ 4) เป็น `labels.zip` และนำเข้า

```bash
python data/dataset.py import labels.zip   # แตกลง data/raw และ data/labels ใช้ชื่อไฟล์เดิมที่อัปโหลด
python data/dataset.py check
```

ภาพที่ถ่ายผ่านปุ่ม "ถ่ายรูป" ในหน้าเว็บได้ชื่อ `capture.jpg` จึงถูกนำเข้าด้วยชื่อ analysis_id ต้องเปลี่ยนชื่อภาพและไฟล์ป้ายกำกับให้ตรงโปรโตคอลเอง ไม่เขียนทับไฟล์ที่มีอยู่แล้ว
