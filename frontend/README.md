# Baht Counter Frontend

React + Vite + TypeScript + Tailwind CSS

## เริ่มใช้งาน

ใช้ Node.js 22.12+ หรือรุ่นที่ Vite รองรับ แล้วรันใน `frontend/`:

```powershell
npm ci
npm run dev
```

เปิด http://localhost:5173 โดย Vite จะส่ง `/api` ไป backend ที่พอร์ต 8000

ทดลองหน้าจอโดยไม่รัน backend (ผลการนับเป็นข้อมูลจำลอง):

```powershell
$env:VITE_USE_MOCK='1'
npm run dev
```

เอาตัวแปรออกด้วย `Remove-Item Env:VITE_USE_MOCK` ก่อนเริ่ม dev server ใหม่เมื่อต้องการใช้ backend

ตรวจโค้ด: `npm run build`, `npm run lint`, `npm test` และ `npm run format:check`
จัดรูปแบบโค้ด: `npm run format`

ไฟล์ใน `frontend/` ใช้ LF โดยกำหนดผ่าน `.gitattributes` ของโฟลเดอร์นี้ เพื่อให้ checkout และตรวจรูปแบบได้เหมือนกันบน Windows และระบบอื่น หากมีไฟล์ CRLF ค้างจาก checkout เก่า ให้รัน `npm run format` ก่อนตรวจรูปแบบ

## หน้าที่มี

- `/`: แดชบอร์ดสีครีม/ส้มอิฐ การ์ดเริ่มนับ และข้อมูลเหรียญ 6 ชนิด
- `/count`: กล้อง อัปโหลด ลากวาง วางภาพจากคลิปบอร์ด และพรีวิว
- `/result/:id`: วงเหรียญบนภาพ ยอดรวม ตาราง เพิ่ม/ลบ/ยืนยันชนิดเหรียญ และดาวน์โหลด JSON/CSV
- `/history`: ประวัติการนับพร้อมแบ่งหน้าและเปิดดูผลซ้ำ
- `/about`: วิธีเตรียมภาพและคำอธิบายขั้นตอนระบบ ใช้ `?analysis=<id>` เพื่อดูภาพกลางทางของผลนั้น

มือถือใช้เมนูด้านล่าง เดสก์ท็อปใช้เมนูด้านซ้าย ภาพประกอบเป็น SVG ในโปรเจกต์
ฟอนต์ Noto Sans Thai และ DM Sans รวมไว้ใน build ผ่าน Fontsource จึงไม่ต้องโหลดจาก Google Fonts และมี system font สำรอง

## เชื่อมต่อ Backend

รัน backend ที่พอร์ต 8000 โดยใช้วิธีใน README หลัก โหมด `COIN_USE_MOCK=0` ใช้โมดูลประมวลผลภาพจริง และ `COIN_USE_MOCK=1` ใช้ผลจำลองจาก backend

การแก้ชนิดเหรียญ ส่งพิกัดเพิ่มเหรียญ และโหลดประวัติ ใช้ schema จาก OpenAPI ปัจจุบัน พิกัด SVG และพิกัดที่ส่ง API เป็นพิกัดภาพต้นฉบับตาม `image_size` หากรูปถูกย่อบนหน้าจอจะคำนวณกลับก่อนส่ง

โหมด `VITE_USE_MOCK=1` ทดลองหน้าจอทั้งหมดได้โดยไม่รัน backend แต่ไม่มีภาพประมวลผลกลางทางและข้อมูลประวัติจะหายเมื่อรีเฟรช โหมดนี้ไม่ได้วิเคราะห์ภาพหรือหาสเกลจริง

การทดสอบครอบคลุมสถานะหน้าจอและ API client ด้วย Vitest การยืนยันกล้องบน Android/iPhone ผ่าน HTTPS และการทดสอบกับผู้ใช้จริงยังต้องทำบนอุปกรณ์จริง

## ภาพ HEIC/HEIF

รับไฟล์จาก iPhone ผ่านตัวเลือกไฟล์หรือลากวาง และส่งไฟล์ต้นฉบับให้ Backend อ่านภาพ หากเบราว์เซอร์แสดงพรีวิวไม่ได้ จะมีข้อความให้กด “ใช้รูปนี้” เพื่อส่งต่อ หรือเลือกภาพใหม่ โดยไม่แปลงหรือลดความละเอียดของไฟล์

ไฟล์ .heic/.heif ที่เครื่องไม่ระบุ MIME จะเติม MIME ตามนามสกุลก่อนส่ง Backend ซึ่งยังตรวจและถอดรหัสไฟล์จริง โหมดทดลองต้องใช้ภาพที่เบราว์เซอร์อ่านได้ หากอ่านไม่ได้จะมีข้อความแนะนำให้ใช้ JPEG/PNG/WebP หรือระบบจริง
